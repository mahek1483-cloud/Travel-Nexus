🌍 Travel Nexus ✈️

Travel Nexus is a smart travel planning platform designed to make trip discovery and planning simple, convenient, and enjoyable.

✨ Features

- 🌍 Explore popular travel destinations
- 🏨 Discover hotels and stays
- ✈️ Plan and organize trips
- 🗺️ Easy-to-use travel interface
- 👤 User-friendly navigation
- 📱 Responsive and modern web design

🎯 Project Objective

Travel Nexus aims to provide travelers with a convenient platform where they can discover destinations, explore accommodation options, and plan their travel experience in one place.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Responsive Web Design
